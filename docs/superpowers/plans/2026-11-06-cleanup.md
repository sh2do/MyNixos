# Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the missing polkit agent and declared look (cursor, icons, GTK theme, font, wallpaper-driven GTK colours), and clear out the leftovers from the Noctalia, DMS and Umbriel era.

**Architecture:** A new Home Manager module, `modules/look/`, owns the polkit agent and the cursor, icon, GTK and font settings. The GTK colours become one more matugen template in `modules/theme/`, so `rice-wall` recolours GTK apps like everything else. The removals are plain edits to `configuration.nix` and git.

**Tech Stack:** NixOS (unstable flake), Home Manager, matugen 4, SDDM (Qt6) with kwin, niri 26.04 KDL.

**Spec:** `docs/superpowers/specs/2026-11-06-cleanup-design.md`

## Global Constraints

- The flake only sees git-tracked files. `git add` new files before any `nix build` or `nix eval`.
- Build check (no sudo): `nix build /etc/nixos#nixosConfigurations.nixos.config.system.build.toplevel --no-link`. The user switches with `! nh os switch`. Never run sudo.
- Don't touch `hp-wmi-omen.nix`, `boot.extraModulePackages`, the Python/nvim deps or `programs.nix-ld`.
- Keep ghostty and kitty installed.
- Values: cursor `Bibata-Modern-Classic` size 24; icons `Papirus-Dark`; GTK theme `adw-gtk3-dark`; GTK font `Rubik 11`; keep dconf `color-scheme = "prefer-dark"`.
- `bash tests/*-test.sh` and `niri validate -c ~/.config/niri/config.kdl` must pass at the end.
- Files outside the repo are deleted only after asking the user in that step, even though the spec lists them.

## Review Focus

1. **Home Manager writing `gtk.css` would clobber the matugen output.** After switching, `~/.config/gtk-4.0/gtk.css` must be the matugen-generated file (a regular file, not a store symlink). Task 3 step 4 checks this.
2. **Xwayland apps (Steam) ignoring the cursor.** They need `XCURSOR_THEME`/`XCURSOR_SIZE`. `home.pointerCursor.x11.enable` and niri's `xcursor-theme` cover it. Task 2 step 5 checks Steam.
3. **The polkit agent must start in any graphical session, not just niri.** It's bound to `graphical-session.target`. Task 1 checks this.
4. **`git rm --cached Configs` must not delete the folder on disk.** Task 4 step 3 checks it's still there.
5. **A fresh clone must still build** after the gitlink is gone. Task 4 step 4.
