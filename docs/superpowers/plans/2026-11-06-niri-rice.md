# Niri Rice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Noctalia/Umbriel/DMS with a from-scratch niri desktop: rotating static wallpapers with matugen colours, a custom Quickshell bar with an animated cobra, rofi menus, a foot/starship/fastfetch terminal, a video lock screen and a video SDDM login.

**Architecture:** Everything lives in a new `modules/` tree. NixOS-level pieces (packages, SDDM, services) are NixOS modules imported from `configuration.nix`. Per-user config (niri KDL, Quickshell QML, rofi, foot, fastfetch, matugen templates) is deployed by Home Manager `xdg.configFile` from `modules/…`. Runtime-generated colour files live in writable paths. One script, `rice-wall`, owns wallpaper state and recolouring. Everything else reads its outputs.

**Tech Stack:** NixOS (flake, unstable), Home Manager, niri 26.04, Quickshell 0.3.2 (QML), matugen 4.2.0, swww 0.12.1, rofi 2.0.0, foot 1.28.0, starship 1.27.0, fastfetch 2.70.0, swayidle 1.9.0, playerctl 2.4.1, SDDM (Qt6) + qtmultimedia 6.12, bash, fish.

**Spec:** `docs/superpowers/specs/2026-11-06-niri-rice-design.md`

## Global Constraints

- The flake only sees git-tracked files. `git add` every new file before any `nix build`.
- Build check (no sudo): `nix build /etc/nixos#nixosConfigurations.nixos.config.system.build.toplevel --no-link`. Switching needs sudo, so ask the user to run `! nh os switch` and report back. Never run sudo yourself.
- Don't touch the user's own work: `hp-wmi-omen.nix`, `boot.extraModulePackages`, the Python and nvim deps, `programs.nix-ld`. Task 0 commits them first.
- XWayland must keep working (niri 26.04 auto-spawns `xwayland-satellite`, which stays installed). Steam must still launch.
- matugen is always called as `matugen image <wall> -t scheme-content --prefer saturation -m dark -c <config>`.
- Rotation interval: 45 minutes.
- Bar height 36–40 px, text ~13 px. Terminal corner radius 12 px.
- Panel: `eDP-2`, 1920x1200 @ 144 Hz. Video backgrounds use the HD (1080p) clips, cropped to fill.
- The cobra art is original, drawn as SVG for this project. Don't copy art from anywhere.
- No live wallpaper on the desktop. Video plays only on the lock and login screens.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **First boot, or `colors.json` missing or corrupt:** the shell, rofi, foot and niri must still start with the fallback palette. Nothing should crash or show black-on-black.
2. **A wallpaper matugen can't read (corrupt file, odd format):** `rice-wall` must still show the wallpaper, keep the previous colours, and exit 0 with a warning.
3. **Hardware or service missing:** no battery, bluetooth adapter absent or blocked, NetworkManager down, no media player. Each bar item hides or shows an "off" state, never an error or empty box.
4. **Very long app titles or track names:** the top pill elides at a fixed max width (520 px) and never grows off-screen.
5. **The bar process has crashed when idle-lock fires:** locking must still work. `rice-lock` is its own process, independent of `qs -c rice`.

Each of these has a test or manual check in its owning task (Tasks 3, 3, 6, 6, 9).
